# Fioles

Jeu de tri de couleurs sans pub : versez les couches d'une fiole à l'autre jusqu'à ce que chaque fiole ne contienne qu'une seule couleur.

## Règles
- Touchez une fiole pour la soulever, puis touchez la fiole où verser.
- On ne verse que sur une couche de même couleur ou dans une fiole vide, dans la limite de 4 couches.
- Chaque niveau est vérifié par un solveur avant d'être proposé : il a toujours une solution.

## Modes
- **Facile** : de 3 à 7 couleurs.
- **Normal** : de 5 à 12 couleurs.

Outils : Annuler, Recommencer, « + Fiole » (une fiole vide en plus, une fois par niveau). La progression est gardée dans le navigateur.

## Jouer sur iPhone
Ouvrir la page GitHub Pages dans Safari, puis Partager → « Sur l'écran d'accueil ».

Tout tient dans un seul fichier : `index.html`.
